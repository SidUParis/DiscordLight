连接到 Discord

轻量、极速、无 Electron 的原生 macOS Discord 客户端。Token 只保存在本机的 macOS 钥匙串（Keychain）里，绝不上传第三方服务器。

如何获取 Token？ 1. 在 Chrome / Safari 打开 Discord 网页版并登录。
2. 按 ⌥+⌘+I 打开开发者工具，切到 Network 标签页。
3. 点击任意请求（如 /messages），复制 Request Headers 中的 Authorization 字段内容。
